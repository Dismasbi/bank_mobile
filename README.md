# BANK MOBILE

A premium mobile banking application built with Flutter.

## Description

BANK MOBILE is a demo banking app that allows users to view their balance, browse transactions, search and filter, see transaction details, make transfers, and switch between light/dark themes.

## Features

- User authentication (simulated login)
- Dashboard with available balance
- List of transactions with search & filter
- Transaction details (parameter passing via GoRouter)
- Transfer form with validation (3 fields)
- Deposit & withdraw dialogs (updated balance)
- Light/Dark theme support
- Responsive layout (mobile & tablet)
- Reusable widgets
- Separation of data and UI
- **Ultra premium color scheme** (deep blue & gold)

## Technologies

- Flutter
- Dart
- Material 3
- GoRouter
- Provider (state management)
- Intl (date formatting)
